## 시작하기

### 요구사항

- Xcode 15.0+
- Tuist 4.0+

### Tuist 설치

```bash
# mise 사용 (공식문서 권장)
mise install tuist

# 또는 Homebrew
brew install tuist
프로젝트 설정

# 1. 저장소 클론
git clone https://github.com/37-dive-sopt-ios/SOPT-Seminar.git
cd SOPT-Seminar

# 2. 의존성 설치
tuist install

# 3. Xcode 프로젝트 생성
tuist generate

# 4. 빌드 할때
스킴 선택
Xcode 상단에서 원하는 세미나 스킴을 선택하여 실행:
스킴	설명
Seminar01	1차 세미나 - UIKit 기초
Seminar02	2차 세미나 - Delegate/Closure
Seminar03	3차 세미나 - TableView/CollectionView
Seminar04	4차 세미나 - 네트워크
Seminar05	6차 세미나 - SwiftUI 기초
Seminar07	7차 세미나 - SwiftUI 심화
```
